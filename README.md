# Mfeti Electrical Solutions

## About the Project

Mfeti Electrical Solutions is a business website designed to provide information about the company's electrical services and make it easy for customers to get in touch.

The website has a simple, professional design using HTML and CSS.

## Website Pages

The website contains the following pages:

- **Home** - Introduction to Mfeti Electrical Solutions
- **About Us** - Information about the business
- **Services** - List of electrical services offered
- **Gallery** - Images related to the business and its work
- **Testimonials** - Customer feedback and reviews
- **Request a Quote** - Allows customers to request a quotation
- **Contact Us** - Contact information and a contact form

## Technologies Used

The website was created using:

- HTML5
- CSS3
