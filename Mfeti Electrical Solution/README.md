3. README File 

Project Title 

Mfeti Electrical Solutions — Company Website 

Project Description 

This repository contains the source code and content for the official website of Mfeti Electrical Solutions (Pty) Ltd, a small electrical services business based in Midrand, Gauteng. The website is designed to advertise the business online, showcase completed work, and allow customers to request quotes and make contact (Mfeti, 2026). 

Technologies Used 

HTML5 (MDN Web Docs, 2025a) 

CSS3 (MDN Web Docs, 2025b) 

JavaScript (MDN Web Docs, 2025c) 

Visual Studio Code 

Git and GitHub 

Google Maps API (Google, 2025) 

Folder Structure 

index.html — Home page 

about.html — About Us page 

services.html — Services page 

gallery.html — Photo gallery page 

testimonials.html — Customer testimonials page 

quote.html — Request a Quote page 

contact.html — Contact Us page 

/css — Stylesheet files 

/js — JavaScript files 

/images — Site images and logo assets 

Installation and Setup 

1. Clone the repository from GitHub to a local machine. 

2. Open the project folder in Visual Studio Code. 

3. Open index.html in a web browser to view the site locally, or use the Live Server extension for real-time previews. 

4. To deploy, upload the project files to the Afrihost web hosting account linked to the domain www.mfetielectrical.co.za (Afrihost, 2026). 

Features 

Responsive, mobile-friendly design 

Google Maps integration showing the business location 

Contact and quote request forms 

WhatsApp click-to-chat button 

Social media links 

Photo gallery of completed work 

Colour Scheme and Typography 

Colours: Dark Blue, Yellow, White. Headings are set in Poppins and body text in Arial, chosen to give the site a professional and easy-to-read appearance (Mfeti, 2026).
