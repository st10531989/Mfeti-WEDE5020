## [1.0.0] - 2026-09-17

### Added

- Created the main Mfeti Electrical Solutions website.
- Added the Home page (`index.html`).
- Added the About Us page (`about.html`).
- Added the Services page (`services.html`).
- Added the Gallery page (`gallery.html`).
- Added the Testimonials page (`testimonials.html`).
- Added the Request a Quote page (`quote.html`).
- Added the Contact page (`contact.html`).
- Added a navigation menu connecting all website pages.
- Added a footer to the website pages.
- Added a contact form to the Contact page.
- Added a quotation request section.
- Added a testimonials section.
- Added a gallery section for business images.

### Styling

- Created a separate CSS stylesheet:
  `css/style.css`
- Added a professional colour scheme.
- Added navy blue for headers, footers and headings.
- Added electrical yellow for buttons, borders and highlights.
- Added white backgrounds for content areas.
- Added light grey backgrounds for sections.
- Added hover effects to navigation links.
- Added styled buttons.
- Added styled contact form fields.
- Added responsive styling for smaller screens.
- Added spacing, borders and shadows to improve the website layout.
